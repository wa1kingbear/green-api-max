# GREEN-API MAX Chat

Небольшой веб-клиент для переписки в MAX через GREEN-API. Пользователь вводит
данные своего инстанса, видит существующие личные чаты и их историю, может найти
нового собеседника по номеру телефона и обмениваться текстовыми сообщениями.

Публичный стенд: <https://157.22.252.17>

## Запуск

Нужны Node.js 20.19+ и pnpm.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

После запуска Vite покажет адрес приложения в терминале. Обычно это
`http://localhost:5173`.

## Проверки

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Для запуска Playwright-тестов:

```bash
pnpm e2e
```

## Стек

- React и TypeScript;
- Vite;
- CSS Modules;
- React Context + `useReducer`;
- Vitest, React Testing Library, MSW и Playwright;
- ESLint, Prettier и pnpm.

Redux здесь не используется намеренно. В MVP один активный чат и небольшой объём
глобального состояния, поэтому Context и reducer покрывают задачу без лишнего
слоя абстракции.

## Работа с GREEN-API

В приложении используются шесть методов:

- `GetChats` — загрузить список личных чатов;
- `GetChatHistory` — загрузить последние сообщения выбранного чата;
- `CheckAccount` — проверить номер и получить `chatId`;
- `SendMessage` — отправить сообщение;
- `ReceiveNotification` — получить следующее событие из очереди;
- `DeleteNotification` — подтвердить обработку события.

После получения списка чатов приложение фоново загружает последнее сообщение для
превью, ограничивая количество одновременных запросов. Полная история загружается
лениво при выборе чата и объединяется с сообщениями из последовательного
long-polling цикла без дублей. После обработки уведомление удаляется из очереди, в
том числе если его тип не поддерживается.

Документация: [GREEN-API MAX](https://green-api.com/max).

## Безопасность

После успешного подключения `idInstance` и `apiTokenInstance` сохраняются в
`localStorage` под ключом `selectedInstance`. Это позволяет восстановить подключение
после перезагрузки страницы. Запись удаляется при нажатии «Выйти», поэтому приложение
не следует подключать на чужом или общедоступном устройстве.

Токен не должен попадать в логи, fixtures, CI или клиентскую конфигурацию.

Переменные с префиксом `VITE_` встраиваются в итоговый JavaScript, поэтому секреты
через них передавать нельзя.
