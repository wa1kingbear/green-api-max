# GREEN-API MAX Chat

Небольшой веб-клиент для переписки в MAX через GREEN-API. Пользователь вводит
данные своего инстанса, находит собеседника по номеру телефона и может обмениваться
с ним текстовыми сообщениями.

## Запуск

Нужны Node.js 20.19+ и pnpm.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

После запуска Vite покажет адрес приложения в терминале. Обычно это
`http://localhost:5173`.

## Проверки

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Для запуска Playwright-тестов:

```bash
pnpm e2e
```

## Стек

- React и TypeScript;
- Vite;
- CSS Modules;
- React Context + `useReducer`;
- Vitest, React Testing Library, MSW и Playwright;
- ESLint, Prettier и pnpm.

Redux здесь не используется намеренно. В MVP один активный чат и небольшой объём
глобального состояния, поэтому Context и reducer покрывают задачу без лишнего
слоя абстракции.

## Как устроен проект

```text
src/
  app/          запуск приложения, контекст и reducer
  pages/        экраны подключения и мессенджера
  shared/       общие компоненты и утилиты
  test/         настройка тестового окружения
```

## Работа с GREEN-API

В приложении будут использоваться четыре метода:

- `CheckAccount` — проверить номер и получить `chatId`;
- `SendMessage` — отправить сообщение;
- `ReceiveNotification` — получить следующее событие из очереди;
- `DeleteNotification` — подтвердить обработку события.

Получение сообщений строится как один последовательный long-polling цикл. После
обработки уведомление удаляется из очереди, в том числе если его тип не
поддерживается или оно относится к другому чату.

Документация: [GREEN-API MAX](https://green-api.com/max).

## Безопасность

`idInstance` и `apiTokenInstance` хранятся только в памяти вкладки и очищаются при
отключении или перезагрузке. Токен не записывается в browser storage и не должен
попадать в логи, fixtures, CI или клиентскую конфигурацию.

Переменные с префиксом `VITE_` встраиваются в итоговый JavaScript, поэтому секреты
через них передавать нельзя.
